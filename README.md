# 🧪 Final Project - Computer Lab 3

Final academic project for the **Laboratorio de Computación III** course. This application simulates a student-course management system and was built using the Java programming language, with a focus on object-oriented programming and MVC design.

## 🚀 Tech Stack

- Java 17
- SpringBoot
- Maven
- JUnit
- Mockito
- Object-Oriented Programming (OOP)

## Documentation  
[Postman Docs](https://documenter.getpostman.com/view/24381036/2sB2ixkEZP)

## 📚 Features

- Registration of students and subjects
- Enrollment simulation
- Academic report generation
